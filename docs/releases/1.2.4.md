# PageQuay 1.2.4

[Français](1.2.4.md) | [English](1.2.4.en.md)

Release du 26 octobre 2026 : protections CAPTCHA, affichage des fenêtres de
vérification et fiabilisation du démarrage Chromium.

- L’attente humaine partage un délai de 120 secondes par job par défaut
  (`PQ_HUMAN_TIMEOUT_SECONDS`). Les reprises ne réinitialisent pas ce délai.
- Les vérifications automatiques sont espacées d’une seconde. Une séquence
  d’attente crée au plus une capture ; les reprises d’extraction face à un CAPTCHA
  instable s’arrêtent après trois captures abandonnées.
- Après expiration ou annulation d’une attente CAPTCHA, le chargement est arrêté,
  JavaScript désactivé et la page suspendue. Si cette opération échoue, PageQuay
  tente de fermer l’onglet. Une navigation, action ou extraction explicite réactive
  une page suspendue. Ces protections ne sont pas un plafond système CPU/mémoire.
- Lorsqu’une intervention humaine est nécessaire, la fenêtre minimisée est
  restaurée et l’onglet CAPTCHA passe au premier plan. Le mode headless est ignoré ;
  un échec d’affichage ne supprime pas la possibilité de reprise manuelle.
- Les opérations de fenêtre et la préparation des captures ont des délais bornés.
  Le démarrage minimisé ne ferme plus un navigateur sain lorsque la confirmation
  native macOS tarde à arriver.
- `POST download_image?wait_seconds=0..10` peut retourner HTTP 200 avec le job
  terminé ; sinon, HTTP 202 et le même ticket. Le défaut reste asynchrone, sans
  replay ni annulation implicite. Les droits sont revérifiés après l’attente.

Le contrat OpenAPI et les versions des paquets passent à 1.2.4. Les dépendances,
les contrôles réseau et les contrats d’URL exacte restent inchangés.

Validation : suite générale, 389 tests réussis et 178 ignorés ; validation ciblée
avec Chromium, 36 tests réussis (CAPTCHA, fenêtres, images et OpenAPI). Ruff,
formatage et diff-check conformes. L’affichage natif macOS est couvert par des
simulations des commandes de fenêtre ; les minuteries sont vérifiées dans Chromium.
Paquets : wheel, archive source et SHA256SUMS. Une installation de la release
nécessite un redémarrage du service pour charger le nouveau code.
