# PageQuay 1.2.3

[Français](1.2.3.md) | [English](1.2.3.en.md)

Release du 24 octobre 2026 : exports Addverb et Greenfield, reprises bornées de
capture et diagnostics réseau. Inclut les commits a64566d et 8328558 depuis 1.2.2.

- Addverb : les blocs JSON-LD vides sont ignorés après les contrôles de nombre et
  longueur ; un JSON non vide invalide reste signalé. Les classes CSS ne consomment
  le budget de sérialisation que pour `include_dom=true`.
- Greenfield : jusqu'à huit enveloppes neutres par chemin, profondeur physique
  maximale 40 ; profondeur sémantique 32, 8 000 nœuds, budgets et exclusions conservés.
  XPath garde sa borne indépendante de 32 segments.
- Une capture non publiée invalidée par `NAVIGATION_CHANGED` peut être relue au plus
  deux fois dans le même job, à URL strictement identique et dans le budget restant.
  Chaque reprise vérifie l'autorisation et prend un nouveau cliché après 250 ms.
  Le reçu expose `capture_restarts` (0 à 2, optionnel pour les anciens résultats).
  Une autre URL ou une instabilité persistante restent refusées sans publication.
- Les refus réseau distinguent document principal, iframe et sous-ressource ; URL
  expurgée, type de ressource et rôle de frame sont bornés. Les précontrôles exposent
  les mêmes diagnostics avant création d'onglet/job. Aucun relâchement DNS/IP/HTTPS.

L'égalité exacte `expected_url`, le schéma structured 1.0 et le signalement des
contenus partiels restent conservés. Les dépendances ne changent pas.

Validation ciblée : 136 tests réussis avec Chromium, couvrant Addverb, Greenfield,
profondeur, refus réseau et courses d'export ; Ruff et diff-check conformes.
Suite générale finale : 366 tests réussis, 177 ignorés (marqueurs navigateur/live).
Le contrat OpenAPI est régénéré pour la version 1.2.3 et le reçu de capture.

Détails : [extraction](../EXTRACTION.md), [Greenfield](../GREENFIELD_EXPORT_REPORT.md),
[diagnostics réseau](../NETWORK_DIAGNOSTICS.md).

Paquets publiés : wheel, archive source et SHA256SUMS. Cette publication ne redémarre
pas le service local ; les recettes d'installation antérieures restent datées dans
leurs rapports respectifs.
