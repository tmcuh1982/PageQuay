# PageQuay 0.2.3

[Français](0.2.3.md) | [English](0.2.3.en.md)

Adds cookie-banner API handling, preserves native Chromium User-Agent and gathers extraction/diagnostic fixes since v0.2.2.

## Changes

- REST/WebSocket validate_cookies: default reject, explicit accept, visible iframe/open-shadow banner detection, detailed cookie_consent result/audit.
- GET/PUT /v1/projects/{slug}/cookie-policy: persistent per-project automatic choice, disabled by default; applies to API visits/search/native pagination and after click/navigation actions.
- Native User-Agent without custom override; robots proof uses the actual browser request header.
- AgXeed stale CDP candidates/export identity/large-document budgets and exact owning target selection for shadow frames.
- Distinguishes embedded CAPTCHA widget from blocking challenge; no automatic solving.
- Bounded network/startup diagnostics without raw messages/private paths/secrets.

## Validation

General: **257 passed/69 skipped** optional browser/diagnostics. Chromium cookies/navigation/acquisition/titles: **37 passed/one skipped**, overlapping sets. Public schema/lock verified; Ruff/format pass for cookie/User-Agent/version files. Pre-existing style differences remain in unchanged diagnostics files.

Cookie action deployed locally and automatic acceptance enabled for UniversRobot only. That private choice is not packaged; other installations default disabled. Service metadata remained 0.2.2 until package reinstall.

## Installation and limits

Additive migration 008_cookie_policy.sql applies at startup. Profiles persist; in-memory tab IDs do not survive restart. Recognition is bounded and exact-label based. Absent choice, ambiguity/scan limits cause no click; reject never becomes accept. clicked proves clicking, not saved consent. Late banners/multi-screen preferences need explicit action. Automatic rules apply to API-driven visits.

Network/auth/challenge guards remain. Native User-Agent does not guarantee Cloudflare access. [README](../../README.en.md), [acquisition](../ACQUISITION.en.md), [OpenAPI](../openapi.json).
