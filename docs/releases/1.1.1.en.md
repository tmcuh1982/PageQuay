# PageQuay 1.1.1

[Français](1.1.1.md) | [English](1.1.1.en.md)

Local release dated October 16, 2026. This commit publishes no tags or packages
and installs or restarts no service.

## Image acquisition without internal Base64

`download_image` replaces binary CDP IO with a Chromium BYOB stream transferred
as bounded integer blocks. After allowed checks finish, the initial image
response is checked at headers and aborted; a controlled empty document permits
a second GET inside Chromium through the existing guards. Final URL, status,
MIME, encoding and length are checked again before reading. The artifact contains
that second response's original bytes, verified size and SHA-256. No direct HTTP
fallback, Base64 or screenshot. Ordinary downloads and universal access stay denied.

Human waiting retains the same job/tab and requires explicit resume even after
manual navigation to the image. Validation uses a disposable, cancellable decoder.
Cleanup errors preserve resource IDs and preceding errors; unpublished artifacts
leave the catalog before physical removal. Admission/payload diagnostics and logs
have more complete correlation without echoing unknown fields.

The client supports `--job-id` and explicit `--resume`, never replays an uncertain
POST and rejects services missing the OpenAPI transport marker
`x-pagequay-image-transport=chromium-byob-integers-v1`. Package, module, OpenAPI and
project lock entry use 1.1.1. No dependency version changed.

## Validation and limitations

Final 1.1.1 preparation: **307 passed, 104 skipped** in 12.43 s; public OpenAPI equals the checked-in schema, Ruff/format/diff checks pass and the lockfile passes offline validation. Locked dependencies match 1.1.0. Existing Starlette/httpx deprecation.

Before version preparation: general suite 307 passed / 104 skipped; targeted
Chromium suite 98 passed. These suites overlap. The authorized October 16 live
recipe used a disposable ASGI service/profile: UBTECH JPEG, 1080 × 1530,
689381 bytes, exact URL, authenticated GET and matching SHA-256. Anonymous 401
and other-project 403 denials passed. Owned tab, service artifact, database and
browser were cleaned up. Initial excessive polling hit the REST quota; the
corrected recipe script subsequently passed. See [the report](../testing/DOWNLOAD_IMAGE_REPORT.en.md).

Limits remain 5 MB and 25 million pixels. No macOS OS RSS ceiling is claimed.
The second GET can fail on source changes or a fresh HTML challenge. No real
Cloudflare challenge was encountered. No installed listener, Tailscale or
UniversRobot integration was tested or changed; no publication approval transfers.
Remote delivery and installation remain separate.
