# PageQuay 1.2.2

[Français](1.2.2.md) | [English](1.2.2.en.md)

23 October 2026 release: exact URL diagnostics and History API navigation evidence.

Unitree G1 redirects `/operate/g1` to `/operate/g1/` with HTTP 302, then removes the
slash through History API several seconds after loading. Acquisition can therefore
observe different destinations at different times. The historical `/g1/` case was
retested separately. See the [report and traces](../testing/UNITREE_URL_SCOPE.md).

- `expected_url` remains exact, including domain, path, slash, query and fragment.
  No approval transfer, global aliases or replacement of the observed URL.
- Rejections expose expected/observed URLs, stage, UTC timestamp, version and available
  tab/job/request/artifact IDs, distinguishing allocated captures from published artifacts.
- Main-document HTTP evidence survives history changes separately from the current URL.
  Bounded commit and CDP History API traces include only the main document. HTTP status
  is never invented for a JavaScript-rewritten path.
- `tab_info` checks URL/title consistency. Structured exports verify their own URL
  before publication and reject inconsistent metadata with `URL_METADATA_MISMATCH`.
  URL identity uses the API's 4096-character bound. HTML remains raw DOM, with navigation
  evidence in the job result.
- `NavigationMetadata` adds optional fields; strict client parsers must accept them.
  Structured schema remains 1.0. UniversRobot is unchanged.

Validation: 350 general tests passed, 157 skipped; 93 targeted tests with Chromium
passed, plus an additional CDP unit test included in the general suite. Local fixtures
cover HTTP slash addition, History API slash removal, domain/path/query changes during
exports, metadata consistency and rejection without publication. Ruff and OpenAPI
checked. Live traces come from disposable instances and do not guarantee future site stability.

Assets: wheel, source archive and `SHA256SUMS`, without private service data.

Local service installed and restarted: exact OpenAPI 1.2.2, readiness and admin/API
boundaries checked; dependency versions and persistent settings preserved.
