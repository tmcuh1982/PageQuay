# PageQuay 1.0.1

Le port de la console administrateur peut désormais être modifié dans **Paramètres → Accès local**, séparément du port API. Les deux ports sont enregistrés ensemble et prennent effet au redémarrage. Les origines loopback autorisées suivent le port administrateur pour conserver le login et la protection CSRF.

Les ports identiques, indisponibles et les modifications concurrentes sont refusés. Les anciens fichiers `local-api.json` contenant uniquement `api_port` restent compatibles. Les valeurs par défaut du serveur restent 8765/8766 ; les exemples clients de cette installation utilisent désormais l’API sur 8787.

## Configuration installée et Tailscale

Console locale : `http://127.0.0.1:8767/admin/`. API locale : `http://127.0.0.1:8787`. La route privée Tailscale Serve existante conserve HTTPS sur 8443 et redirige vers 8787 ; les clients distants conservent leur URL et leur clé. Cette configuration de machine n’est pas appliquée automatiquement par l’installation du paquet. Après un changement du port API, adapter explicitement la destination Serve.
