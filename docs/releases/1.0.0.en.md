# PageQuay 1.0.0

[Français](1.0.0.md) | [English](1.0.0.en.md)

First v1 release of the private macOS browser gateway: separate persistent profiles, per-project REST/WebSocket, search, actions, extraction/screenshots. It reuses validated 0.2.4 code with package/module/OpenAPI/lock set to 1.0.0; browser code is unchanged between these commits.

## Delivered behavior

- French local console, scoped/quota-bound API keys, asynchronous jobs, protected artifacts and isolated profiles.
- Search adapters, navigation with exact scope/redirect checks, bounded DOM/iframe extraction, screenshots and redacted diagnostics.
- validate_cookies and per-project automatic choice, disabled by default; explicit acceptance and observed click result.
- Native Chromium User-Agent/persistent Playwright context; installed Chrome or bundled Chromium, default chromium.
- Private Playwright-pipe relay to the child browser's explicit nonzero loopback CDP port, validated endpoint/cleanup.
- Native page-WebSocket refusal through a second proxy before DNS/upstream, without replacing constructor or direct fallback; frames/popups/workers covered. PQ command WebSocket remains.
- Sandbox/public validated-IP proxy/redirect/Service Worker/permission/download guards preserved.

## Validation

Base full Chrome/Chromium suite: **343 passed, four skipped**, existing Starlette/TestClient/httpx warning. Targeted Ruff/format/offline lock/diff pass. Version-only update: **six public-contract tests passed**, offline lock/Ruff/diff pass.

Installed fresh Chrome/Chromium profiles successfully searched/opened Music Store. One retained Chromium session completed five searches/five product HTTP 200 navigations without observed Cloudflare challenge. First Fender click timed out; pages were then opened by API navigation to observed links. [Protocol/limits](../BROWSER_TRANSPORT.en.md).

## Archives and installation

pagequay-1.0.0-py3-none-any.whl, pagequay-1.0.0.tar.gz and SHA256SUMS are built from tagged sources. Wheel includes JavaScript/templates/assets/migrations; sdist includes scripts/docs. No database/key/private configuration/capture/profile shipped.

Python >=3.12,<3.15 and macOS GUI for visible mode; follow [README](../../README.en.md). Existing additive migrations apply at startup; v1 introduces no additional one. Normal updates preserve profiles/keys/settings.

Local CDP has no authentication: trusted local processes only, never proxy/tunnel/Serve it. Proxy is not OS firewall. No automatic CAPTCHA solving or guarantee of protected-site availability. Other-device access, ACL and complete restore validation remain partial. GitHub publication does not install into the existing service; at this historical release it retained 0.2.2 metadata/Chromium config and the already deployed runtime fix, without restarting the demo session.
