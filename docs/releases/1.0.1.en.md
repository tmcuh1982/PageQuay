# PageQuay 1.0.1

[Français](1.0.1.md) | [English](1.0.1.en.md)

Administrator port is now configurable under **Paramètres → Accès local**, separately from API port. Both are saved together and take effect after restart. Allowed loopback origins follow the admin port to preserve login/CSRF.

Identical/unavailable ports and concurrent edits are rejected. Older local-api.json files containing only api_port remain compatible. Server defaults stay 8765/8766; this installation's client examples now use API 8787.

## Installed configuration and Tailscale

Local admin http://127.0.0.1:8767/admin/, API http://127.0.0.1:8787. Existing private Serve keeps HTTPS 8443 and forwards to 8787; remote clients retain URL/key. These machine settings are not automatically applied by package installation. Explicitly update Serve destination after changing the API port.
