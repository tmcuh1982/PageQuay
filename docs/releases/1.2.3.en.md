# PageQuay 1.2.3

[Français](1.2.3.md) | [English](1.2.3.en.md)

24 October 2026 release: Addverb and Greenfield exports, bounded capture retries and
network diagnostics. Includes commits a64566d and 8328558 since 1.2.2.

- Addverb: ignore empty JSON-LD blocks after existing count/length checks; malformed
  nonempty JSON remains flagged. CSS classes consume serialization budget only with
  `include_dom=true`.
- Greenfield: up to eight neutral envelopes per path, absolute physical depth 40;
  counted semantic depth 32, 8,000 nodes, other budgets and exclusions remain.
  XPath retains its separate 32-segment bound.
- An unpublished capture invalidated by `NAVIGATION_CHANGED` may be recaptured at
  most twice within the same job, only at the exact same URL and within the remaining
  budget. Each retry checks authorization and takes a fresh capture after 250 ms.
  Receipts expose `capture_restarts` (0 to 2, optional for older results).
  A changed URL or persistent instability remains rejected without publication.
- Network refusals distinguish the main document, child frames and subresources;
  sanitized URL, resource type and frame role are bounded. Navigation preflight
  exposes the same diagnostics before tab/job creation. DNS/IP/HTTPS guards remain.

Exact `expected_url`, structured schema 1.0 and partial-content reporting are preserved.
Dependency versions remain unchanged.

Targeted validation: 136 tests passed with Chromium, covering Addverb, Greenfield,
depth, network refusals and export races; Ruff and diff checks passed. OpenAPI was
regenerated for version 1.2.3 and the capture receipt. Final general suite: 366 tests
passed, 177 skipped (browser/live markers).

Details: [extraction](../EXTRACTION.en.md), [Greenfield](../GREENFIELD_EXPORT_REPORT.md),
[network diagnostics](../NETWORK_DIAGNOSTICS.md).

Assets: wheel, source archive and SHA256SUMS. This publication does not restart the
local service; earlier deployment recipes retain their dates in their own reports.
