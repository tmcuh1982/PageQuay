## Original image acquisition

New REST command POST /v1/projects/{slug}/download_image acquires original JPEG, PNG or WebP bytes through the browser and existing proxy without reencoding. The job returns a private binary artifact, size, SHA-256, expiry and navigation metadata. A Python example verifies the download/hash before publishing its local file.

The expected final URL is mandatory and matched exactly. Requires content:read and browser:interact, limits data to 5 MB and applies a total deadline including queue/human waiting. Format/completeness validation, animation refusal, quotas, cancellation, revocation and uncommitted-artifact removal are covered. Pillow dependency added. [Contract](../DOWNLOAD_IMAGE.en.md), [October 15 evidence](../testing/DOWNLOAD_IMAGE_REPORT.en.md).

## Extraction and configuration

aria-hidden="true" iframes are omitted from structured extraction even when dimensioned/visible to Playwright, without consuming content-frame slots.

Includes 1.0.1: separate configurable administrator/API ports, port validation and loopback-origin adaptation. [1.0.1 notes](1.0.1.en.md).
