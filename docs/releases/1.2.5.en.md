# PageQuay 1.2.5

[Français](1.2.5.md) | [English](1.2.5.en.md)

2 November 2026 release. Includes d782b5a and 8956387 since version 1.2.4.

- **Opt-in static AVIF**: validate the complete ISO-BMFF original before decoding
  in the existing disposable process. Maximum dimensions 8192 per axis and
  16 million pixels; animation is rejected. Defaults remain JPEG/PNG/WebP.
  MIME refusals include bounded `observed_mime` details.
- **Clearpath**: up to eight visible documents including the main document, with
  the existing 40-second total and 10-second per-frame deadlines.
- **Sunflower**: excluded data URLs no longer trigger URL-length truncation.
  HTML export can omit binary data-media attributes on a cloned DOM; its receipt
  exposes `html_derivation`, omission details and the HTML SHA-256. The live DOM
  and document text remain intact.
- **Dense documents and long attributes**: 16000 nodes, 400 controls, URLs up to
  4096 characters, text budget min(1000000, max_content_bytes/4). Attribute limits:
  title 16384 characters, alt/aria-label 4096, frame names 131072. Exceeding limits
  still produces explicit truncation and partial flags.
- **Empty initial frames**: a child frame without a URL may be omitted without
  spending a content read only after an isolated probe verifies pristine about:blank.
- **Search**: normalize Unicode and whitespace in end-of-results notices without
  rewriting results. Unrecognized engine pages remain rejected, with a private
  project HTML diagnostic artifact when storage is available.
- **CAPTCHA deadline**: `human_verification` exposes the wait budget and timestamps,
  also retained in expiry error details. Resuming does not reset the deadline.

OpenAPI and packages align on 1.2.5. Dependencies and exact URL, network and access
controls are unchanged. These limits do not guarantee completeness for every site;
actual omissions remain explicit.

Adaptation validation: general suite 451 passed / 179 skipped, and 68 targeted
checks with Chromium. Publication validation for 1.2.5: general suite rerun, 451 passed and 179 skipped;
Ruff, formatting, diff checks and offline lockfile validation pass.

Published packages: wheel, source archive and SHA256SUMS. Publication does not
automatically update the local installation or restart the service.
