# PageQuay 1.2.2

[Français](1.2.2.md) | [English](1.2.2.en.md)

Release du 23 octobre 2026 : diagnostics URL exacts et preuve des réécritures History API.

Unitree G1 redirige `/operate/g1` vers `/operate/g1/` en HTTP 302, puis retire le slash
par History API quelques secondes après chargement. L'acquisition peut donc rencontrer
deux destinations différentes selon l'instant du contrôle. Le cas historique `/g1/`
a été retesté séparément. Voir le [rapport et ses traces](../testing/UNITREE_URL_SCOPE.md).

- L'égalité `expected_url` reste exacte : domaine, chemin, slash, query et fragment.
  Aucun transfert d'approbation, alias global ou remplacement de l'URL observée.
- Les refus exposent attente, observation, étape, horodatage UTC, version et IDs
  tab/job/request/artifact disponibles. Une capture allouée puis jetée est distinguée
  d'un artefact publié.
- Preuve HTTP principale conservée séparément de l'URL courante ; commits et événements
  CDP History API bornés, limités au document principal. Aucun statut HTTP inventé pour
  un chemin réécrit par JavaScript.
- `tab_info` contrôle la cohérence de l'URL et du titre. Le structured contrôle son URL
  propre avant publication et renvoie `URL_METADATA_MISMATCH` en cas d'incohérence.
  L'identité URL utilise la borne API de 4096 caractères. Le HTML reste le DOM brut,
  accompagné de la preuve de navigation dans le résultat du job.
- `NavigationMetadata` reçoit des champs optionnels ; les parseurs clients stricts
  doivent les accepter. Le schéma structured reste 1.0. Aucun changement UniversRobot.

Validation : 350 tests généraux réussis, 157 ignorés ; 93 tests ciblés avec Chromium
réussis et un test unitaire CDP supplémentaire inclus dans la suite générale. Les
fixtures locales couvrent redirection ajoutant un slash, History API retirant un slash,
changement de domaine/chemin/query pendant les exports, métadonnées et refus sans
publication. Ruff et OpenAPI vérifiés. Les traces réelles proviennent d'instances
jetables ; elles ne garantissent pas la stabilité future du site.

Paquets : wheel, archive source et `SHA256SUMS`, sans données privées du service.

Service local installé et redémarré : OpenAPI 1.2.2 exact, disponibilité et frontières
admin/API vérifiées ; dépendances et réglages persistants conservés.
